# Economics of the Global Energy Transition — H Heuristics Research Report № 2025-03

**Single-page digital report.**  
Investment gaps, stranded assets, and the fiscal implications of rapid decarbonization.

## Deploy

This site is deployed via GitHub Pages. Any push to `main` triggers a rebuild.

## Local Development

Open `index.html` in a browser. No build step required.  
Charts rendered client-side via Chart.js 4.4.0 (CDN).
